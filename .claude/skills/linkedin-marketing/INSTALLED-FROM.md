Installed 2026-09-11.

These are **interactive Claude Code skills**: draft -> human approval -> publish.
They are not part of the unattended Railway agent, which cannot invoke skills.

Publishing here is via Publora, a third-party SaaS. It is NOT configured, and
should stay that way: the agent already publishes directly to the LinkedIn API
with no per-month cap. Left unconfigured, these skills run in draft-only mode
(Tier 0) and need no keys.

See the LinkedIn agent README for which rules from this bundle were ported into
the automated pipeline, and which were deliberately not.
