# Microns — design plan

## Palette (one accent)
| token | hex | role |
|---|---|---|
| `--ink` | `#14181C` | primary type |
| `--porcelain` | `#F3F4F2` | page base |
| `--mist` | `#DDE1DF` | hairlines, quiet surfaces |
| `--micron` | `#1B3FD1` | links, primary button, signature moment |
| `--slate` | `#5A6570` | secondary type only |

Deep instrument blue: cool enough not to warm the porcelain, dark enough for AA
on the base and for white type on the button.

## Type
Two families, clearly distinct — the split is the brief's tension (technical
service, aesthetic buyer).

- **Display:** Instrument Serif, one weight, high contrast.
- **Body/UI:** Schibsted Grotesk, 17-19px, generous leading, measure < 75ch.

## Layout concept
The page is a measuring instrument. A hairline scale column with small numeric
markers runs down the left of interior sections; content sits in an asymmetric
right measure. Sections alternate full-bleed / contained / narrow so the page
has rhythm. No cards anywhere — rules and emptiness separate.

## Principles
1. Money left, mechanism right. Every section leads with the revenue
   consequence, never the machinery.
2. One hairline, one accent, one display weight.
3. The micron metaphor appears once, structurally, never as decoration.
4. Nothing is a card.

## Signature element
Considered: (a) timestamped depiction of a recovered lead, (b) oversized
typographic hero, (c) precision-instrument metaphor at scale.

Chosen: **a fused with c.** A vertical hairline scale in the hero down which
three timestamped events resolve once on load - missed call, reply sent 38
seconds later, booked at 09:12. Captioned as an illustration so it reads as a
depiction, not a statistic. Everything after it is still.

## Self-critique and revision
The scale column and single-weight serif alone would have suited any B2B agency
site. Two changes made:

- The hero instrument now depicts this product's specific mechanism (the
  60-second reply) rather than an abstract ruler.
- The five systems drop cards for a stepped table carrying real trigger
  metadata (24h/2h reminders, 5-day review wait, 2-hour callback SLA) taken
  from the workflows in this repo. Section 5.7 makes specificity the trust
  device, so it belongs in the layout, not only the copy.
